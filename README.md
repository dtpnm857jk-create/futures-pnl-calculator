# 合約損益計算器（免費版）

免費、可在瀏覽器內完成計算的 USDT／USDC 本位線性永續合約損益計算器。輸入開平倉價、數量、手續費率與資金費，即可看出扣完成本後的實際淨損益。

**線上使用：** [https://dtpnm857jk-create.github.io/futures-pnl-calculator/](https://dtpnm857jk-create.github.io/futures-pnl-calculator/)

本頁面不含任何人名。本工具不保證獲利，也不是投資建議。

## 功能

- 支援做多／做空
- 分別輸入開倉、平倉手續費率（以百分比輸入，例如 0.05 代表 0.05%）
- 資金費可記「收到」或「支付」，金額填正數
- 以十進位精確運算，顯示四捨五入至小數第 8 位
- 可在手機瀏覽器使用，也可加到主畫面
- 計算全程在你的裝置上完成

## 計算公式（摘要）

- 做多毛損益 ＝（平倉價 − 開倉價）× 幣數
- 做空毛損益 ＝（開倉價 − 平倉價）× 幣數
- 開倉手續費 ＝ 開倉價 × 幣數 × 開倉費率
- 平倉手續費 ＝ 平倉價 × 幣數 × 平倉費率
- 總成本 ＝ 開倉手續費 ＋ 平倉手續費 ＋ 支付的資金費 − 收到的資金費
- 淨損益 ＝ 毛損益 − 總成本

實際金額以交易所結算為準（費率、折扣、資金費、強平等因素可能不同）。
